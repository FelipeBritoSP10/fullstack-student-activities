# 📄 Atividade 02 — HTML

## 🎯 Objetivo
Criar uma página de **receita culinária**, praticando listas, tabelas e organização de conteúdo longo em seções semânticas.

## 📋 Enunciado
Crie um `index.html` com:

1. **Cabeçalho** com o nome da receita e uma imagem ilustrativa
2. **Seção de informações rápidas**: tempo de preparo, rendimento e dificuldade, organizados em uma `<table>`
3. **Seção de ingredientes**: lista (`<ul>`) com pelo menos 8 itens
4. **Seção de modo de preparo**: lista ordenada (`<ol>`) com pelo menos 6 passos
5. **Seção de avaliação**: um `<form>` simples com nome, nota (`<select>` de 1 a 5) e comentário (`<textarea>`)
6. **Rodapé** com créditos do autor da receita

## ✅ Requisitos técnicos
- Usar tags semânticas (`<header>`, `<main>`, `<section>`, `<footer>`)
- Tabela com `<thead>` e `<tbody>` corretos
- `<select>` com pelo menos 5 `<option>`
- Sem CSS ou JavaScript

## 📦 Entrega
```bash
git checkout -b feat/html-atividade-02
```
Desenvolver em `01-html/atividade-02/`, testar, commitar e abrir o Pull Request.

## 🧠 O que você deve conseguir explicar
- Por que usou `<ol>` para o modo de preparo e `<ul>` para os ingredientes
- Estrutura de uma tabela HTML (`<thead>`, `<tbody>`, `<tr>`, `<td>`, `<th>`)
- Diferença entre `<select>` e `<input>`
