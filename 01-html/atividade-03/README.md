# 📄 Atividade 03 — HTML

## 🎯 Objetivo
Criar uma **landing page de evento** (palestra, workshop ou festa), praticando formulário de inscrição e organização de conteúdo promocional.

## 📋 Enunciado
Crie um `index.html` com:

1. **Seção principal (hero)**: nome do evento, data, local e uma chamada de destaque
2. **Sobre o evento**: parágrafo explicando do que se trata
3. **Programação**: tabela ou lista com horários e atividades
4. **Palestrantes/convidados**: lista com nome e uma breve descrição de cada um
5. **Formulário de inscrição**: nome, e-mail, telefone e um `<select>` com tipo de ingresso
6. **Localização**: um link (`<a>`) para o Google Maps do endereço
7. **Rodapé** com redes sociais do evento (links)

## ✅ Requisitos técnicos
- Tags semânticas bem definidas
- Formulário com `required` nos campos obrigatórios
- Todos os links devem abrir corretamente
- Sem CSS ou JavaScript

## 📦 Entrega
```bash
git checkout -b feat/html-atividade-03
```
Desenvolver em `01-html/atividade-03/`, testar, commitar e abrir o Pull Request.

## 🧠 O que você deve conseguir explicar
- Para que serve o atributo `required` em um `<input>`
- Diferença entre `<section>` e `<article>` nesse contexto
- Como estruturou a hierarquia de títulos (`<h1>` a `<h3>`)
