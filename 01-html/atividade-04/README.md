# 📄 Atividade 04 — HTML

## 🎯 Objetivo
Criar um **currículo (CV) online**, praticando organização de conteúdo pessoal/profissional em uma estrutura clara e acessível.

## 📋 Enunciado
Crie um `index.html` com:

1. **Cabeçalho**: nome, cargo/objetivo e informações de contato
2. **Resumo profissional**: um parágrafo curto
3. **Experiência profissional**: lista com empresa, cargo, período e descrição de cada experiência
4. **Formação acadêmica**: tabela com curso, instituição e período
5. **Habilidades técnicas**: lista de tecnologias/competências
6. **Idiomas**: lista com nível de cada idioma
7. **Links**: LinkedIn, GitHub e/ou portfólio

## ✅ Requisitos técnicos
- Estrutura acessível (usar `<h1>` uma única vez, hierarquia correta de headings)
- Uso de `<time>` para datas, quando aplicável
- Todos os links funcionando (`target="_blank"` em links externos)
- Sem CSS ou JavaScript

## 📦 Entrega
```bash
git checkout -b feat/html-atividade-04
```
Desenvolver em `01-html/atividade-04/`, testar, commitar e abrir o Pull Request.

## 🧠 O que você deve conseguir explicar
- Por que a hierarquia de headings importa para acessibilidade
- Para que serve `target="_blank"` e o que é boa prática usar junto (`rel="noopener"`)
- Como organizou as informações por ordem de relevância
