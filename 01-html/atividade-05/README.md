# 📄 Atividade 05 — HTML

## 🎯 Objetivo
Criar um **artigo de blog**, praticando estruturação de texto longo, citações e navegação entre conteúdos.

## 📋 Enunciado
Crie um `index.html` com:

1. **Cabeçalho do artigo**: título, autor e data de publicação
2. **Corpo do texto**: pelo menos 4 parágrafos, divididos em subtítulos (`<h2>`)
3. **Uma citação** usando `<blockquote>`
4. **Uma imagem** com legenda usando `<figure>` e `<figcaption>`
5. **Lista de artigos relacionados**: links para outras páginas (podem ser fictícias)
6. **Seção de comentários (estática)**: pelo menos 2 comentários simulados, cada um com nome e texto
7. **Rodapé** com informações do blog

## ✅ Requisitos técnicos
- Uso correto de `<article>` para o conteúdo principal
- `<figure>` e `<figcaption>` usados corretamente
- Hierarquia de headings coerente
- Sem CSS ou JavaScript

## 📦 Entrega
```bash
git checkout -b feat/html-atividade-05
```
Desenvolver em `01-html/atividade-05/`, testar, commitar e abrir o Pull Request.

## 🧠 O que você deve conseguir explicar
- Diferença entre `<article>` e `<section>`
- Para que serve `<figure>`/`<figcaption>`
- Por que usar `<blockquote>` em vez de aspas dentro de um `<p>`
