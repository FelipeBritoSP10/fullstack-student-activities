# 🎨 Atividade 02 — CSS

## 🎯 Objetivo
Estilizar a página de receita (Atividade 02 de HTML) usando **CSS Grid**, praticando layout em grade.

## 📋 Enunciado
1. Usar `display: grid` na seção de ingredientes + modo de preparo, colocando lado a lado em telas grandes e empilhado em telas pequenas
2. Estilizar a tabela de informações rápidas (bordas, cores alternadas nas linhas)
3. Definir uma paleta de cores consistente (tons quentes, por exemplo)
4. Estilizar o formulário de avaliação com espaçamento e bordas arredondadas
5. Adicionar pelo menos uma `media query` para ajustar o grid em telas menores

## ✅ Requisitos técnicos
- Uso de `grid-template-columns` e `gap`
- CSS em arquivo separado
- Classes organizadas e reutilizáveis

## 📦 Entrega
```bash
git checkout -b feat/css-atividade-02
```
Desenvolver em `02-css/atividade-02/`, testar responsividade, commitar e abrir o Pull Request.

## 🧠 O que você deve conseguir explicar
- Diferença entre Grid e Flexbox e por que escolheu Grid aqui
- Como funciona `grid-template-columns`
- Como a media query altera o layout
