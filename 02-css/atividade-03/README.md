# 🎨 Atividade 03 — CSS

## 🎯 Objetivo
Estilizar a landing page de evento (Atividade 03 de HTML), combinando **Flexbox e Grid** na mesma página.

## 📋 Enunciado
1. Seção hero: usar Flexbox para centralizar texto e botão de inscrição
2. Seção de palestrantes: usar Grid para organizar os cards em colunas responsivas
3. Programação: estilizar como uma linha do tempo (usando `border-left` e espaçamento)
4. Botão de inscrição com estado `:hover` e `:active`
5. Pelo menos 2 media queries (tablet e mobile)

## ✅ Requisitos técnicos
- Combinar Flexbox (para alinhamentos simples) e Grid (para grades de cards)
- Cores e tipografia consistentes com a identidade de um evento
- CSS separado e organizado

## 📦 Entrega
```bash
git checkout -b feat/css-atividade-03
```
Desenvolver em `02-css/atividade-03/`, testar em diferentes telas, commitar e abrir o Pull Request.

## 🧠 O que você deve conseguir explicar
- Quando usar Flexbox e quando usar Grid
- Como funciona `:hover` e `:active`
- Como decidiu os breakpoints das media queries
