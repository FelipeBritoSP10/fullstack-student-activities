# 🎨 Atividade 04 — CSS

## 🎯 Objetivo
Criar um **dashboard simples** (cards com métricas fictícias), praticando Grid responsivo e componentização visual.

## 📋 Enunciado
1. Criar um HTML novo com 6 "cards" de métricas (ex: Vendas, Usuários, Receita, etc.), cada um com título, número grande e uma variação percentual
2. Organizar os cards em Grid responsivo (4 colunas em desktop, 2 em tablet, 1 em mobile)
3. Usar cores diferentes para indicar variação positiva (verde) e negativa (vermelho)
4. Adicionar uma barra lateral fixa (`position: fixed` ou `sticky`) com um menu de navegação
5. Sombra e `border-radius` nos cards para dar profundidade

## ✅ Requisitos técnicos
- Grid responsivo com no mínimo 3 breakpoints
- Uso de variáveis CSS (`:root { --cor-principal: ... }`)
- Sem sobreposição de elementos em nenhum tamanho de tela

## 📦 Entrega
```bash
git checkout -b feat/css-atividade-04
```
Desenvolver em `02-css/atividade-04/`, testar em várias resoluções, commitar e abrir o Pull Request.

## 🧠 O que você deve conseguir explicar
- Para que servem variáveis CSS e como usou
- Diferença entre `position: fixed` e `position: sticky`
- Como o grid se adapta entre os breakpoints
