# 🎨 Atividade 05 — CSS

## 🎯 Objetivo
Criar uma página de **portfólio pessoal** com transições e animações simples em CSS.

## 📋 Enunciado
1. Seção de projetos: cards com imagem, título e descrição, que aumentam levemente (`transform: scale`) ao passar o mouse
2. Usar `transition` para suavizar os efeitos de hover
3. Criar uma animação simples com `@keyframes` (ex: um ícone ou botão "pulsando" ou um elemento que aparece com fade-in ao carregar a página)
4. Menu de navegação fixo no topo, com efeito de sombra ao rolar a página (pode simular sem JS, aplicando sombra direto)
5. Rodapé com ícones de redes sociais que mudam de cor no hover

## ✅ Requisitos técnicos
- Uso de `transition` em pelo menos 3 elementos
- Uso de `@keyframes` em pelo menos 1 animação
- Sem exageros — animações devem ser sutis e rápidas (200–400ms)

## 📦 Entrega
```bash
git checkout -b feat/css-atividade-05
```
Desenvolver em `02-css/atividade-05/`, testar as animações, commitar e abrir o Pull Request.

## 🧠 O que você deve conseguir explicar
- Diferença entre `transition` e `animation`/`@keyframes`
- Por que animações muito longas ou exageradas prejudicam a experiência
- Como funciona `transform: scale()`
