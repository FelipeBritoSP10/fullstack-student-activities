# ⚙️ Atividade 05 — JavaScript

## 🎯 Objetivo
Criar um **quiz interativo** com pontuação, unindo lógica, DOM, eventos e arrays/objetos.

## 📋 Enunciado
1. Criar um array de objetos com pelo menos 5 perguntas, cada uma com: pergunta, alternativas e resposta correta
2. Exibir uma pergunta por vez na tela, com as alternativas como botões
3. Ao clicar em uma alternativa, indicar visualmente se acertou (verde) ou errou (vermelho), e mostrar a resposta correta
4. Avançar automaticamente (ou com botão "Próxima") para a pergunta seguinte
5. Ao final, mostrar a pontuação total ("Você acertou X de 5 perguntas")
6. Botão "Reiniciar" que zera o quiz e embaralha as perguntas novamente

## ✅ Requisitos técnicos
- Perguntas armazenadas em array de objetos (estrutura de dados organizada)
- Lógica de embaralhamento das perguntas (pode usar `Math.random()`)
- Sem repetir pergunta na mesma rodada
- Código dividido em funções claras

## 📦 Entrega
```bash
git checkout -b feat/js-atividade-05
```
Desenvolver em `03-javascript/atividade-05/`, jogar o quiz várias vezes testando acertos e erros, commitar e abrir o Pull Request.

## 🧠 O que você deve conseguir explicar
- Como estruturou o array de perguntas e por quê
- Como funciona a lógica de pontuação
- Como implementou o embaralhamento das perguntas
