# ⚙️ Atividade 01 — Tailwind CSS

## 🎯 Objetivo
Criar um **Cartão de Perfil (Profile Card)** elegante e moderno, unindo fundamentos de layout, flexbox, espaçamento, sombras e estados de interatividade.

## 📋 Enunciado
1. Criar um container principal centralizado na tela (vertical e horizontalmente) com fundo contrastante
2. Construir o cartão de perfil contendo uma foto de avatar circular com borda de destaque
3. Exibir o nome completo do usuário, cargo/profissão e uma breve biografia descritiva
4. Adicionar uma seção de estatísticas ou links de redes sociais com ícones representativos
5. Incluir um botão de chamada para ação ("Seguir" ou "Conectar") com efeito de transição suave no `hover`
6. Garantir que o componente seja responsivo e mantenha uma proporção agradável em diferentes tamanhos de tela

## ✅ Requisitos técnicos
- Uso de Flexbox para alinhamento e distribuição dos elementos internos (`flex`, `flex-col`, `items-center`, `justify-center`)
- Aplicação de utilitários de bordas e arredondamento (`rounded-full`, `rounded-2xl`, `border`)
- Uso de sombras e elevação para dar profundidade ao card (`shadow-lg`, `hover:shadow-xl`)
- Transições e animações básicas (`transition-all`, `duration-300`, `hover:scale-105`)
