# ⚙️ Atividade 02 — Tailwind CSS 

## 🎯 Objetivo
Criar um **Grid de Cards de Produtos** simples para praticar o uso de cores, espaçamentos e a criação de uma grade responsiva básica.

## 📋 Enunciado
1. Criar um título simples para a página: "Nossos Produtos"
2. Criar uma lista com 4 cartões de produtos
3. Fazer o layout se adaptar aos tamanhos de tela:
   - 1 coluna em telas pequenas (mobile)
   - 2 colunas em telas médias (tablet)
   - 4 colunas em telas grandes (desktop)
4. Cada cartão deve ter:
   - Uma imagem simples
   - Nome do produto
   - Preço
   - Um botão "Comprar"

## ✅ Requisitos técnicos
- Uso do grid do Tailwind (`grid`, `grid-cols-1`, `md:grid-cols-2`, `lg:grid-cols-4`)
- Espaçamento entre os elementos (`gap-4`, `p-4`)
- Arredondamento e bordas simples (`rounded-lg`, `border`)
- Botão estilizado com cor de fundo e texto claro (`bg-blue-600`, `text-white`)
