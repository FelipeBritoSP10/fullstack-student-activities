# ⚙️ Atividade 03 — Tailwind CSS: Navbar Simples

## 🎯 Objetivo
Criar uma **Barra de Navegação (Navbar)** responsiva utilizando Flexbox e utilitários de alinhamento.

## 📋 Enunciado
1. Criar um cabeçalho fixo no topo da página com fundo escuro.
2. Posicionar o nome da marca/logo à esquerda.
3. Colocar 3 links de navegação à direita ("Início", "Sobre", "Contato").
4. Esconder os links em telas pequenas e exibi-los a partir de telas médias (`md`).
5. Adicionar efeito de mudança de cor nos links ao passar o mouse (`hover`).

## ✅ Requisitos técnicos
- Uso do Flexbox para distribuição espacial (`flex`, `justify-between`, `items-center`).
- Espaçamento interno e margens (`px-6`, `py-4`, `gap-6`).
- Visibilidade condicional por breakpoint (`hidden`, `md:flex`).
- Efeitos simples de hover no texto (`text-gray-300`, `hover:text-white`).
